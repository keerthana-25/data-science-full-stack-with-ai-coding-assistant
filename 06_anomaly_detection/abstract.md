# Abstract

This project reproduces the core idea of **Anomaly Threat Intelligence** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on anomaly detection and uses Credit-card-fraud style synthetic data. The main experiment is: Synthetic normal and anomalous points, Isolation Forest scoring, ROC-AUC evaluation, visual inspection. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
