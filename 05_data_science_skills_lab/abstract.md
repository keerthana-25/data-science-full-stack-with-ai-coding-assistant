# Abstract

This project reproduces the core idea of **Data Science Skills Mastery Lab** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on end-to-end data science skills and uses Iris (scikit-learn). The main experiment is: EDA, scaling, PCA, classification, cross-validation, feature importance and model evaluation using the Iris dataset. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
