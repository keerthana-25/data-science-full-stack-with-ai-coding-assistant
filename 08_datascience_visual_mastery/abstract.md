# Abstract

This project reproduces the core idea of **Data Science Visual Foundations** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on data science education and uses Iris + generated mathematical examples. The main experiment is: Naive Bayes classifier, confusion matrix metrics, gradient descent simulation, visual learning artifacts and quiz bank. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
