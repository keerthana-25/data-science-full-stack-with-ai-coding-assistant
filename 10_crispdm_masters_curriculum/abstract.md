# Abstract

This project reproduces the core idea of **CRISP-DM Masters Platform** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on integrated crisp-dm workflow and uses Breast Cancer Wisconsin (scikit-learn). The main experiment is: One compact workflow covering EDA, KMeans, Isolation Forest, Random Forest classification, simple association rules, approximate neighbor search and synthesis. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
