# Abstract

This project reproduces the core idea of **Multimodal AutoML Suite** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on multimodal classification and uses Synthetic tabular + text + image-signal benchmark. The main experiment is: Combines tabular, simple text-count and image-summary features, then runs an automated classifier tournament. AutoGluon is optional when installed. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
