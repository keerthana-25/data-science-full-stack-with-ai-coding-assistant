# Abstract

This project reproduces the core idea of **FlowForge DAG Engine** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on data pipeline orchestration and uses Synthetic pipeline graph. The main experiment is: Directed acyclic graph validation, topological execution order, task status simulation and dependency visualization. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
