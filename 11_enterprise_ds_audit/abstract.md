# Abstract

This project reproduces the core idea of **Enterprise Data Science Audit** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on governance and reproducibility and uses This repository. The main experiment is: Static audit of sibling projects for required files, seed usage, train/test discipline markers and documentation completeness. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
