# Push to GitHub

Suggested repository: `keerthana-25/data_science_examples`

After creating an empty public repository in GitHub, run:

```bash
git remote add origin https://github.com/keerthana-25/data_science_examples.git
git branch -M main
git push -u origin main
```

If the remote already exists, use `git remote set-url origin ...` instead of `git remote add origin ...`.
