# Abstract

This project reproduces the core idea of **TimePulse Forecasting Engine** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on time series forecasting and uses Airline-passenger style synthetic seasonal series. The main experiment is: Chronological split, lag features, linear and random-forest forecasts, MAE/RMSE comparison, no random shuffling. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
