# Abstract

This project reproduces the core idea of **Market Basket Pattern Mining** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on association rule mining and uses Online Retail style transaction data. The main experiment is: Deterministic basket transactions, item and pair support, confidence and lift calculation, top association rules. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
