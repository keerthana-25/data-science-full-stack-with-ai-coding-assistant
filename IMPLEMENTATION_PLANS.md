# Master Implementation Plans
Each project has its own detailed `IMPLEMENTATION_PLAN.md`. This file gives the portfolio-level sequence.
1. Preserve the supplied prompt.
2. Define a laptop-friendly experiment.
3. Use a deterministic seed.
4. Separate training/evaluation where applicable.
5. Save metrics and plots.
6. Generate a simple dashboard.
7. Audit the implementation.
8. Capture a browser screenshot.
9. Document how to reproduce the result.
