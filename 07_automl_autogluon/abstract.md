# Abstract

This project reproduces the core idea of **AutoML Model Tournament** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on automated model selection and uses Breast Cancer Wisconsin (scikit-learn). The main experiment is: Lightweight AutoML-style tournament across logistic regression, random forest, gradient boosting and KNN using cross-validation. README includes optional AutoGluon upgrade path. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
