# Abstract

This project reproduces the core idea of **NYC Taxi Trip Duration Predictor** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on supervised regression and uses NYC Taxi Trip Duration (Kaggle). The main experiment is: Synthetic NYC-like trip data, train/test split, baseline linear regression, random forest regression, MAE/RMSE/R2 comparison. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
