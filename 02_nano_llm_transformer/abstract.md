# Abstract

This project reproduces the core idea of **NanoLlama Language Model Lab** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on language modeling and uses Tiny educational text corpus (offline reproduction). The main experiment is: Small character n-gram language-model baseline with deterministic training corpus, perplexity estimate, and text generation. Kept intentionally laptop-friendly. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
