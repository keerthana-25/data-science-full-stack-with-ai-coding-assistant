# Abstract

This project reproduces the core idea of **SPY Time Series Forecasting Lab** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on financial time series and uses SPY-style synthetic price series; accepts real CSV input. The main experiment is: Leakage-safe lagged-return forecasting with walk-forward holdout, directional accuracy, RMSE and simple long/cash strategy diagnostics. Real SPY CSV can replace offline synthetic data. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
