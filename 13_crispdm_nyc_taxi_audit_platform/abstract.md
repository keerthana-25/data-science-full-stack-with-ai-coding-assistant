# Abstract

This project reproduces the core idea of **CRISP-DM NYC TLC Audit Platform** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on audited regression and explainability and uses NYC TLC style synthetic trip data. The main experiment is: NYC-like regression with chronological-style partitioning, model comparison, feature importance, clustering of pickup coordinates and explicit audit checks. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
