# Abstract

This project reproduces the core idea of **Customer Intelligence Clustering** as a compact, laptop-friendly data science experiment. The work follows the CRISP-DM sequence from problem definition through evaluation and communication. The implementation focuses on unsupervised clustering and uses Mall Customer Segmentation style data. The main experiment is: Customer-like synthetic data, standardization, KMeans model search over k, silhouette score selection, cluster visualization. Results are generated by the included code and saved as machine-readable metrics and a visualization. Reproducibility and leakage checks are documented separately.
